# Архитектура папок как она есть

## Основные доменные зоны проекта

В проекте реализованы 2 доменные зоны:

```md
|- backend/ - весь бэкенд в его эпостази
|- infra/ - вся логика деплоя
```
## Каталоги в backend/

Здесь все разделено по реализуемой логике

```md
|- api/ - все, что связано с ручками, зависимостями для ручек, исключениями на ручках
|- management/ - конфиг проекта и функция инициализации логгера
|- migrations/ - миграции алембик
|- services/ - сервисный слой, разделенный на Redis и Database, в нем описывается 
непосредственно подключение, инициализация сессии, репозиторий слой для токенов в редисе
модели, операции к бд, енумы и пр.
|- test/ - тесты
|- Dockerfile - логика сборки бэкенда в контейнере
|- ...файлы с зависимостями
```
